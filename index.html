Note de pe Google

Cu o cheie Google Places API proprie, unealta de zonă aduce notele și numărul de recenzii pentru restaurante și magazine, și le poate ordona după notă. Mai important: cu cheie, toată căutarea de zonă trece pe Google — de la peste un minut la sub o secundă, cu program și note incluse.

Cum o obții: console.cloud.google.com → proiect nou → activezi Places API (New) → Credentials → Create API key. Google cere card chiar și pentru gratuit. O zonă căutată costă maximum 6 apeluri. Cererea include și programul, ceea ce poate urca factura la nivelul Enterprise, cu 1.000 de apeluri gratuite pe lună — adică peste 150 de căutări lunar, mult peste ce ai nevoie. Restricționează cheia pe HTTP referrer cu adresa site-ului tău și pune o cotă zilnică mică, ca să dormi liniștit.
